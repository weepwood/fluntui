# Fluent System Info (fluntui)

一个基于 **C++17、Qt 6 Widgets、FluentQt** 的电脑信息展示与性能监控 Demo。

- 系统总览：CPU、内存、磁盘、运行时间
- 硬件详情：处理器、显示适配器、操作系统
- 网络监控：下载、上传速率和累计流量
- FluentQt 原生窗口、按钮、卡片和进度条
- Windows x64 自动构建、测试与 GitHub Release 发布
